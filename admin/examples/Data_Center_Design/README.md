# Data Center Design 

## Project Description
**Project No** 
349024

**Project Title** 
Data Center Design Project 

**Project Details**
To design, construct, and commission a Tier III [Tier level] data center facility with 10 megawatts of critical IT load capacity by Q4 2026, ensuring 99.982% uptime, achieving a PUE (Power Usage Effectiveness) of 1.3 or lower, and securing LEED certification within a $50M budget.
